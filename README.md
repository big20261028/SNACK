# SNACK

Spring 기반 실시간 사용자 참여형 SNS 커뮤니티 서비스입니다.  
작가들이 창작물을 공유하고, 사용자는 게시글·댓글·좋아요·구독 기능을 통해 소통할 수 있도록 구현했습니다.

## 프로젝트 개요

SNACK은 창작물 공유를 중심으로 한 SNS 커뮤니티 서비스입니다.  
회원 인증, 게시글 CRUD, 댓글, 좋아요, 구독/팔로우, 마이페이지 기능을 구현하며 Spring MVC 기반 웹 서비스 구조를 경험했습니다.

## 주요 기능

- 회원가입, 로그인, 이메일 인증
- 게시글 등록, 조회, 수정, 삭제
- 댓글 작성 및 삭제
- 좋아요 기능
- 사용자 구독/팔로우 기능
- 구독한 사용자의 게시글 조회
- 마이페이지 및 방명록 기능

## 담당 역할

- 회원, 게시글, 댓글, 좋아요, 구독 관계를 고려한 DB 설계
- MyBatis Mapper 기반 데이터 CRUD 로직 구현
- 사용자 인증 및 커뮤니티 핵심 기능 구현
- SVN을 활용한 형상관리 및 협업 진행

## 배운 점

초기에는 화면 기능 구현에 먼저 집중했지만, 댓글·좋아요·구독 기능이 추가되면서 데이터 관계와 DB 구조의 중요성을 체감했습니다.  
이 경험을 통해 기능 구현 전 데이터 관계와 조회 흐름을 먼저 정리하는 것이 중요하다는 점을 배웠습니다.
